# ai-finance-billing-ops 账单运营诊断助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

账单运营诊断助手用于回答「账单哪里不清楚」、财务运营、定价分析、指标诊断，适合金融、运营、创始人、software在明确业务目标、内容材料或分析对象后调用。
它会结合财务材料或指标说明、粘贴财务文档、指标口径、账单信息、定价背景、业务假设或关注问题。等输入，整理关键上下文，并输出信息整理、风险提示、待人工复核问题清单，便于继续执行、复盘或交付。
能力定位补充：面向ECC的以证据为先的收入、定价、退款、团队计费和计费模型真相工作流。当用户需要销售快照、定价比较、重复收费诊断或基于代码的计费现实而非通用支付建议时使用。

### 什么时候使用

**适用场景**

- 用户提出“账单哪里不清楚”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 金融、运营、创始人、software需要围绕账单运营诊断助手生成信息整理、风险提示、待人工复核问题清单
- 用户已经准备了财务材料或指标说明（粘贴财务文档、指标口径、账单信息、定价背景、业务假设或关注问题。）、财务资料文件（上传财务文档、指标表、账单、价格表、业务测算或参考资料。）、财务资料链接（填写公开可访问的财务资料、价格页、报告或参考链接。），希望整理成可执行的分析或优化结果
- 用户需要把账单运营诊断助手相关材料转成清晰结论、优先级和下一步动作

### 调用方式

通过导出的 Python runner 直接调用 AI Skills API：

### 命令示例

**基础调用**

```bash
python3 scripts/run.py --params '{}'
```

**带常用参数调用**

```bash
python3 scripts/run.py --params '{"materialText":"财务材料或指标说明"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `materialText` | string | 否 | - | 粘贴财务文档、指标口径、账单信息、定价背景、业务假设或关注问题 |
| `materialFile` | string | 否 | - | 上传财务文档、指标表、账单、价格表、业务测算或参考资料 |
| `materialUrl` | string | 否 | - | 填写公开可访问的财务资料、价格页、报告或参考链接；需要传可访问的完整 URL |
| `audience` | string | 否 | - | 说明结果面向财务、运营、创始团队、销售或其他决策角色 |
| `goal` | string | 否 | - | 说明要解释的指标、定价问题、账单争议、利润目标或决策用途 |
| `brandRequirements` | string | 否 | - | 补充时间范围、币种、计量口径、假设条件、不可替代专业判断的边界或复核重点 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 信息整理、风险提示、待人工复核问题清单：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合财务材料或指标说明（粘贴财务文档、指标口径、账单信息、定价背景、业务假设或关注问题。）、财务资料文件（上传财务文档、指标表、账单、价格表、业务测算或参考资料。）、财务资料链接（填写公开可访问的财务资料、价格页、报告或参考链接。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「账单运营诊断助手」的核心问题。
- 再检查结果是否覆盖信息整理、风险提示、待人工复核问题清单，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
